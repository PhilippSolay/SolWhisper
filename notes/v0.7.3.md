## Fixed

**Dictation with the Apple Speech engine works again when Siri and Dictation are turned off in macOS.** v0.7.2 started forcing on-device recognition for privacy, but on Macs where both Siri and System Settings → Keyboard → Dictation are off, macOS reports on-device support while the recognizer actually refuses to start — every dictation silently produced nothing: no paste, no history entry.

SolWhisper now tries on-device first and, if the recognizer dies before producing any text, retries once through Apple's servers — replaying the audio already captured so your first words aren't lost. If Apple speech recognition is unavailable entirely, you now get a clear message with the fix (turn on Dictation in System Settings → Keyboard, or switch engines in Settings → Dictation) instead of a dictation that goes nowhere.

**Privacy note:** when the server fallback kicks in, that dictation's audio is processed by Apple rather than on-device. The fallback is recorded in the debug log. To guarantee on-device Apple recognition, enable Dictation in System Settings → Keyboard (macOS then keeps the offline speech model installed) — or use the WhisperKit engine, which is always local.
