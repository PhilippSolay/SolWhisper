# SolWhisper v0.6.2

The 0.6 release that actually ships. v0.6.0 and v0.6.1 packaged a stale binary due to a release-script bug (it picked an old build product), so this is the first 0.6.x DMG that contains the real new code **and** a working auto-updater.

## What's in 0.6.x

- 🌐 **Translate from screen** — snip any on-screen text, get the translation on your clipboard.
- **Meeting pipeline progress** — Transcribe → Clean → Diarize → Summarize shown as a staged strip; polished summaries; cancel button for in-flight diarization.
- **Reliability & performance** — summaries no longer time out on long meetings (5-min timeouts + streaming), transient provider errors auto-retry, faster/cheaper summaries (pre-pass type classification, collapsed transcript, Anthropic prompt caching), and real diarization upload progress.
- **Voice profiles** — un-stuck voiceprint capture; existing name-only profiles backfill to stored voiceprints.

## Release-tooling fixes (why 0.6.2 exists)

- **Monotonic build numbers** — `CFBundleVersion` is now minutes-since-epoch instead of a per-build counter, so a release never falls behind a dev machine (which made Sparkle say "you're up to date" against a newer release).
- **No more stale packaging** — the release script now selects the freshest build product and verifies its version matches the release before packaging, instead of grabbing whichever DerivedData dir sorted first.

## Compatibility & known limitations

- **macOS 14+** required.
- **Notarization** — signed but **not yet notarized**. macOS may warn on first launch; right-click → Open (or System Settings → Privacy & Security → Open Anyway) the first time.

## Upgrade

- **Sparkle auto-update** — installed users are prompted automatically once the appcast updates.
- **Fresh install** — download the DMG from the GitHub release page.
- **Settings preserved** — model configs, skill packs, voice profiles, and meeting history carry forward unchanged.
