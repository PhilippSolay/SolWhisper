## Fixed

**Downloading the large-v3-turbo model works now.** The picker was pointing at a model ID that never existed in the WhisperKit model repository, so every download attempt failed with "No models found matching…". The picker now uses the real repository ID for OpenAI's turbo checkpoint (`large-v3-v20240930`), and any saved selection of the old ID is migrated automatically on first launch — no settings to redo.

**Model downloads survive switching settings panes.** Previously, clicking to another settings section mid-download threw away the progress UI while the download kept running invisibly — and coming back showed "✓ available offline" for a model that was only half on disk. Download progress now lives outside the settings views: navigate away and back and the progress bar picks up where it was. A model only shows the "available offline" checkmark once every file it needs is actually present, and an interrupted download resumes from where it stopped instead of hiding behind a false checkmark.

## New

**large-v3-turbo (compressed)** — a 597 MB quantized build of the turbo model with near-best accuracy, for when the full 1.5 GB download is overkill. Available in Settings → Models for both Dictation and Meetings.

**First universal build for Intel Macs.** Alongside the Apple Silicon DMG, this release ships a `-universal` DMG that also runs on Intel. If you're on Apple Silicon, stick with the regular DMG — it's half the size.

**Honest download sizes in the model picker.** The old labels quoted the models' parameter counts as megabytes; the picker now shows the real download sizes (tiny.en 145 MB, base.en 139 MB, small.en 463 MB, turbo 597 MB / 1.5 GB).
