# SolWhisper v0.6.0

A new on-screen translation tool, a far smoother meeting pipeline, and a round of reliability fixes that make long-meeting summaries and diarization stop timing out.

## Headline feature

### 🌐 Translate from screen
Capture any text on screen and get an instant translation on your clipboard — no copy-paste, no switching apps.

- **Screen-snip OCR** — drag a region, the text is recognized locally.
- **Translate to clipboard** — the result lands on your clipboard, ready to paste anywhere.
- Polished result bubble with a clean dismiss flow.

## Meetings

- **Live pipeline progress** — Transcribe → Clean → Diarize → Summarize now show as a staged progress strip so you can see exactly where a meeting is in processing.
- **Polished summaries** — cleaner Markdown output and better section structure.
- **Cancel button for diarization** — stop an in-flight diarize run cleanly instead of waiting it out.

## Reliability & performance

- **Summaries no longer time out on long meetings.** Per-request timeouts raised from the 60-second default to 5 minutes, and summaries now stream as they generate — so a multi-minute generation keeps the connection alive instead of failing with "The request timed out."
- **Transient provider errors auto-retry.** 502 / 503 / 504 / rate-limit and network blips retry with backoff instead of surfacing as a hard failure. HTTP errors now read as plain sentences rather than raw HTML.
- **Faster, cheaper summaries.** A cheap pre-pass classifies the meeting type so the summary prompt ships only the relevant template (≈21k fewer input tokens), consecutive same-speaker segments are collapsed, and the static skill prompt is cached on Anthropic for big repeat-run savings.
- **Diarization upload progress.** AssemblyAI and Deepgram now stream the audio from disk and show real upload progress, so the bar no longer parks at 5% during the multi-minute upload of a long recording.

## Voice profiles

- **Un-stuck voiceprint capture** — capturing a voiceprint no longer hangs.
- **Backfill** — existing name-only profiles graduate to stored voiceprints.

## Fixes

- Meeting recording: drop stray chunks beyond the first; more reliable calendar auto-linking.
- Audio: release the vDSP DFT setup on stop (no leak).
- Meeting: allow restarting after any ScreenCaptureKit failure.
- Deepgram: stop printing raw transcript output to the log.

## Compatibility & known limitations

- **macOS 14+** required.
- **Notarization** — this build is signed but **not yet notarized** by Apple. macOS may warn on first launch; right-click → Open (or System Settings → Privacy & Security → Open Anyway) the first time. Notarized builds resume once the Developer ID is in hand.

## Upgrade

- **Sparkle auto-update** — installed users are prompted automatically once the appcast updates.
- **Fresh install** — download the DMG from the GitHub release page.
- **Settings preserved** — model configs, skill packs, voice profiles, and meeting history carry forward unchanged.
