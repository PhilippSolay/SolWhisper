# SolWhisper v0.4.0-alpha.2 — Full Walkthrough Test Program

**Build under test:** v0.4.0-alpha.2 (build 36+)
**Estimated walkthrough time:** ~75–90 min for everything; can split across sessions.
**Prereqs:** macOS 13+, working microphone, internet (for Deepgram + OpenRouter), optional: another Mac for Hermes/Obsidian endpoints.

Run top-to-bottom on a clean install. Each row is one check; tick when verified. Sections **A–N** are progressive — later sections build on earlier permissions/state.

---

## A. Setup & first launch (~5 min)

| Pass | Check |
|:--:|---|
