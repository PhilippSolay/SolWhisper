# SolWhisper v0.4.0-alpha.4 — Test Protocol

A pragmatic checklist for verifying the v0.4 build before sharing with testers.
Run top-to-bottom on a clean install.

## 0. Setup

- [ ] **TCC reset** — uninstall any prior SolWhisper, remove from
      System Settings → Privacy & Security → Microphone / Speech / Accessibility / Screen Recording / Automation.
- [ ] **Install** the v0.4.0-alpha.2 build via `scripts/deploy-local.sh debug`
      or the staged DMG (when notarized).
- [ ] **First launch** — onboarding should appear if `hasCompletedOnboarding` is unset.
- [ ] **Permissions check** — alert lists missing permissions; grant Microphone,
      Speech Recognition, Accessibility, Automation; relaunch.

## Sprint 0 — Foundations

### Notarization (still pending)

- [ ] When Developer ID Application cert is in Keychain, set `DEVELOPMENT_TEAM`
      in `project.yml` and `SW_TEAM_ID` env var.
- [ ] Run `scripts/release.sh 0.4.0-alpha.2 …` — confirms `xcrun notarytool submit`
      succeeds and `xcrun stapler staple` validates.
- [ ] Install notarized DMG → upgrade from a prior notarized build → permissions
      persist (no TCC re-prompt).

### Keychain migration

- [ ] Pre-condition: have `openRouterApiKey` set in UserDefaults from an old build.
- [ ] Launch v0.4.0-alpha.2 once — log shows `🔐 Keychain migration · openRouterApiKey moved from UserDefaults`.
- [ ] Re-launch — no migration log (idempotent).
- [ ] Settings → AI Polish → API Key field shows the migrated key.
- [ ] Verify in Keychain Access app: entry `cloud.solay.SolWhisper / openRouterApiKey` exists.

### Schema versioning

- [ ] Open `~/Library/Application Support/SolWhisper/Meetings/<any>/meeting.json` —
      confirm `"schemaVersion": 1`.
- [ ] Manually set `"schemaVersion": 99` and reload Transcripts window —
      that meeting should be silently skipped (logged in DebugLog).

## Sprint 1 — WhisperKit backend

- [ ] Settings → Transcription → Backend → **WhisperKit**.
- [ ] Click **Download base.en now** — progress bar advances; after download
      "✓ base.en available offline" appears.
- [ ] Hit `⌥⌘Space`, speak ~30 s of mixed prose (with filler "um", "like"),
      stop. Pill shows `(transcribing on stop…)`.
- [ ] Result pastes into the active window. Special-token regex passes —
      no `<|startoftranscript|>` markers leak.
- [ ] Switch backend to **Apple Speech**, repeat — works identically.
- [ ] Switch to **Deepgram** (with API key), repeat — works identically.
- [ ] In Settings → Transcription, change WhisperKit model to `tiny.en` —
      `WhisperKitClient.resetCache()` runs; next dictation uses tiny.

## Sprint 2 — File import (mode B)

- [ ] Tray → **Upload audio file…** → pick a 5-min `.mp3`. Progress window:
      Validating → Copying → Loading model → Transcribing X% (with audio position) → Writing → Done.
- [ ] Click **Reveal in Finder** — `~/Library/Application Support/SolWhisper/Meetings/<date>-<slug>/`
      contains `audio.mp3`, `meeting.json`, `transcript.json`, `transcript.md`, `session.log`.
- [ ] Drop a `.wav` onto the SolWhisper Dock icon — same flow runs.
- [ ] Cancel mid-import: progress window closes immediately; partial folder
      moves to Trash (gone from `Meetings/`).
- [ ] Try a corrupt file (rename `foo.txt` to `foo.mp3`) — fails with "Couldn't
      read audio at foo.mp3. Is it a supported format?"

## Sprint 3 — Transcripts window

- [ ] Tray → **Transcripts…** (or `⌥⌘T`) — window opens.
- [ ] Sidebar shows imports grouped by Today / Yesterday / This Week / Earlier.
- [ ] Filter field narrows by title prefix.
- [ ] Click a meeting — right pane: title, date, duration, source app, backend.
- [ ] Click **▶︎** — audio plays. Drag slider — scrubs. Click any segment
      timestamp — audio jumps + plays from there.
- [ ] "12 meetings · Open folder" footer — clicking opens Meetings folder.
- [ ] Empty state ("No meetings yet") shows when folder is empty.

## Sprint 4a — Core meeting recording

### Permission first-run

- [ ] Tray → **Record meeting**. macOS prompts for **Screen Recording**.
      Grant → relaunch SolWhisper.
- [ ] Click again — privacy disclaimer appears (Sprint 8). Click Continue.

### Mic + system capture

- [ ] Open another app and play audio (a 1-min YouTube clip).
- [ ] Click **Record meeting** — pill appears in `.meeting` mode.
- [ ] Hover the pill — buttons are **⏸ Pause** (left) + **⏹ Stop** (right).
      No X / cancel button.
- [ ] Speak into mic during the YouTube clip.
- [ ] Click **Stop** — pill shows processing dots; tray menu reads
      "Transcribing meeting…"; eventually idle; Transcripts window auto-opens.

### Outputs

- [ ] Meeting folder contains:
  - [ ] `audio.wav` (mixed)
  - [ ] `audio_mic.wav` (your voice)
  - [ ] `audio_system.wav` (the YouTube audio)
  - [ ] `transcript.json` with segments tagged `[Me]` and `[Other]`
  - [ ] `transcript.md` (human-readable)
  - [ ] `meeting.json`, `session.log`
  - [ ] `chunks/` directory should be gone (cleaned up post-stitch)
- [ ] Open `transcript.md` — segments interleave by start time.

### Pause / resume

- [ ] Start a meeting → hover pill → click **Pause** → pause icon shows.
- [ ] Hover paused pill → click **Resume** → continues recording.
      (Audio buffers during pause are dropped, not appended.)

### Crash recovery

- [ ] Start meeting, record ~45 s.
- [ ] Activity Monitor → Force Quit SolWhisper.
- [ ] Relaunch. After ~2 s, dialog: "Recover unfinished meeting?"
- [ ] Click Recover — DebugLog shows `🛟 Recovering orphan meeting`.
      (For v0.4-alpha, recovery just flags the session; full re-stitching
      lands in v0.5.)
- [ ] Click Discard — orphan meeting is preserved on disk (user can
      manually delete chunks/ or the whole folder).

## Sprint 4b — Audio quality (partial in v0.4-alpha)

- [ ] **Shipped:** `AudioMixer.swift` (RMS ducking) + `ClippingDetector.swift`
      exist as standalone components — full wiring into the live mix

- [ ] **Deferred to v0.5:** `DeviceMonitor` (BT/USB hot-swap), dual-meter

## Sprint 6 — Integrations

### Hermes (your VPS)

- [ ] Set webhook URL + HMAC secret (stored in Keychain, not UserDefaults).
- [ ] Toggle Enabled.
- [ ] Settings → Meetings → enable "Auto-send to integrations after summary".
- [ ] Record a meeting. After processing, DebugLog shows `🌐 Hermes sent · HTTP 200`.
- [ ] On Hermes side: confirm signature in `X-Webhook-Signature` matches
      HMAC-SHA256(body, secret).
- [ ] Disable Hermes → no send fires next time.

### Obsidian

- [ ] Settings → Integrations → Obsidian card.
- [ ] Click **Choose…** → pick your Obsidian vault folder.
- [ ] Set subfolder ("Calls"), filename template (`{{date}}-{{slug}}.md`).
- [ ] Toggle Enabled.
- [ ] Record/import → DebugLog `📓 Obsidian written · 2026-05-03-meeting-1645.md`.
- [ ] Open Obsidian → file appears in `Calls/` with title, summary, transcript,
      and audio link to `audio.wav`.

### Generic webhook

- [ ] Generic webhook UI is **deferred to v0.5** — only Hermes + Obsidian

### Failed-send retry queue

- [ ] **Deferred to v0.5.** v0.4-alpha logs failures via DebugLog;
      durable retry queue with exponential backoff lands later. If a send
      fails, manually re-trigger by editing the meeting and re-running.

## Sprint 9 — General app polish (alpha.3)

These cover the five settings items added after Sprint 8: OCR auto-detect, additive
clipboard, launch-on-login, error logging, and recording retention.

### 9.1 OCR — Auto-detect language

- [ ] Settings → **Screen Capture** → Recognition section now shows
      **Recognition language** picker + **Automatically detect language** toggle.
- [ ] With auto-detect **off**, pick "German". Snip a screenshot of mixed-language
      text — recognition prefers German.
- [ ] Toggle **Automatically detect language** ON. The Recognition language picker

### 9.2 Additive clipboard

- [ ] Settings → **STT Short** → Output section now shows **Additive clipboard**
      toggle. With it OFF, dictation behaves as before: each transcript replaces
      the clipboard.
- [ ] Toggle **Additive clipboard** ON. The footer caption appears explaining
      the behavior + Accessibility requirement. **Clear automatically** toggle
      appears nested below it (default ON).
- [ ] Copy "hello world" manually (⌘C from any app).
- [ ] Trigger dictation, say "this is a test", stop. Open a text field and ⌘V →
      pastes `hello world\n\nThis is a test.` (existing clipboard content +
      separator + new transcript).
- [ ] Trigger another dictation, say "more text", stop. ⌘V → pastes
      `hello world\n\nThis is a test.\n\nMore text.` (further appended).
- [ ] **Clear-on-paste** (Accessibility required):
  - [ ] After pasting, wait ~200ms then ⌘V again — clipboard is empty (cleared
        after the last ⌘V landed).
  - [ ] DebugLog shows `📋 Clear-on-paste · cleared after ⌘V`.
- [ ] **changeCount safety:** dictate → before pasting, manually copy something
      else (e.g. select text and ⌘C). Now ⌘V → the clipboard is NOT wiped
      (DebugLog: `📋 Clear-on-paste skipped · pasteboard changed since write`).
- [ ] Toggle **Clear automatically** OFF → after dictating + pasting, the
      clipboard still holds the appended buffer; further ⌘V keeps pasting it.
- [ ] Toggle **Additive clipboard** OFF mid-session → next dictation REPLACES
      clipboard (back to default behavior). DebugLog `📋 Clear-on-paste tap`
      shows the tap was torn down.
- [ ] **No-AX path:** Revoke Accessibility in System Settings → relaunch.
      Toggle Additive Clipboard + Clear automatically ON → DebugLog warns
      `📋 Clear-on-paste skipped · Accessibility not granted`. The append still
      works; only the auto-clear is disabled.

### 9.3 Launch on login

### 9.5 Keep recordings for (retention sweep)
